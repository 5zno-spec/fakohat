# فكوهات

لعبة فواكه (match-3) بملف واحد: index.html

## التثبيت كتطبيق
تظهر نافذة زجاجية لتثبيت اللعبة بعد ثانية من فتحها على الحاسوب والهاتف. اللعبة نفسها تعمل من `index.html` وحده، أما الملفات التالية فتجعلها قابلة للتثبيت (ضعها بجانب `index.html`):

- `manifest.webmanifest`
- `sw.js`
- `icon-192.png` و `icon-512.png`

لإعادة إظهار النافذة أثناء التجربة افتح الصفحة مع `?install=1`.
